# LibrarySystem

Энгийн PHP-MySQL номын сангийн удирдлагын систем. Хэрэглэгчид ном үзэх, унших, үнэлэх, зээлэх боломжтой, админ нь ном удирдах болон зээлэлтийг хянах боломжтой.

---

## Онцлог

- Хэрэглэгч бүртгэл, нэвтрэлт  
- Админ болон хэрэглэгчийн эрх  
- Ном үзэх, онлайн унших, PDF татах  
- Ном зээлэх, хугацааг хянах  
- Ном үнэлэх  
- Хайлтын түүх хадгалах  
- Аватар зураг оруулах, удирдах  

---

## Шаардлагууд

- WAMP/XAMPP/LAMP сервер  
- PHP 8+  
- MySQL 5.7+  
- Вэб хөтөч  

---

## Суулгалт

1. Репозиторийг clone хийх эсвэл ZIP-аар татаж авна:  

git clone https://github.com/Usukhjargal1029/LibrarySystem.git
Төслийн фолдерыг серверийн www эсвэл htdocs фолдерт хуулна.
Сервер (Apache & MySQL) ажиллуулна.
Мэдээллийн сангийн тохиргоо

phpMyAdmin нээнэ (http://localhost/phpmyadmin)

Шинэ мэдээллийн сан үүсгэнэ, жишээ: library_db(dummy)

SQL файлыг импортлоно:
Файл: \www\LibrarySystem\sql\library_db_dummy_(1).sql
Import → Файл сонго → Go дарна
Анхны нэвтрэх мэдээлэл

Админ:

Email: admin@yahoo.com

Нууц үг: password

Хэрэглээ

Вэб хөтөчөөр нээнэ:

http://localhost/LibrarySystem

Дээрх нэвтрэх мэдээллээр нэвтэрнэ.

Ном үзэх, зээлэх, үнэлэх, удирдах функцуудыг ашиглана.
API түлхүүрүүдийг .env эсвэл тохиргооны файлуудад оруулна.
